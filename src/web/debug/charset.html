ZX81 semigraphics

Every glyph below is drawn from the 8×8 bitmaps in the original ZX81 ROM (emulator/roms/zx81.rom, character set at 0x1E00; inverse characters are the same bitmap with all bits flipped). Nothing here is a Unicode approximation. The emulator rendering of the same characters is shown at the bottom.

Keyboard entry

Press SHIFT+9 to switch to GRAPHICS mode (the cursor shows G). In GRAPHICS mode a shifted key gives the graphics symbol printed on its keycap, and an unshifted key gives the inverse of its normal character. The keycap-to-glyph assignment is printed on the ZX81 keyboard; it is not restated here. SHIFT+9 again leaves the mode. CHR$ code works for every row in the table.

Emulator rendering

The graphics program prints codes 0–10 on the first line and 128–138 on the second.
