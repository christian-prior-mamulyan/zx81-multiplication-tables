Navigation bar alternatives

Five horizontal bars in Solarized orange. Each has its own content and its own styling. All stay on one row; on a phone they scroll sideways. Try one on the game page with the link below each bar.

1 · Brand and links

Content: the site's mark on the left (a quarter block and "cprima", linking to career.cprima.net); Play, How to play, The program and GitHub on the right, each with a Font Awesome Pro icon. Styling: a solid orange band, cream text, the current page underlined.

Open the game page with this bar

2 · Where am I

Content: a breadcrumb trail, career.cprima.net › ZX81 multiplication tables, and a "Source on GitHub" link at the end. No section links. Styling: a cream strip with one thick orange rule below, the horizontal element of the identity and nothing else.

Open the game page with this bar

3 · Sections

Content: three in-page tabs, Play, How to play and The program, with a count on each (steps to read, lines of BASIC). Styling: rounded tabs on a sand bar, the current tab filled orange.

Open the game page with this bar

4 · Game status

Content: not links but live values from the emulated ZX81: its state, the BASIC line being executed and the emulated time, plus a link to the listing. (Here the numbers are simulated; on the game page they come from the emulator.) Styling: a monospace status bar in Solarized orange all over, with a dark rule below; the labels are small cream tags.

Open the game page with this bar

5 · ZX81 menu

Content: a numbered keyword menu in capitals: 1 PLAY, 2 HOW TO PLAY, 3 LISTING, 4 SOURCE. Styling: monospace on orange, the numbers and the current entry in inverse video, as the ZX81 shows inverse characters.
