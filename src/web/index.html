ZX81 Multiplication Trainer

The game is over.

How to play
  1. Type how many seconds you want to wait (1 to 99) and press Enter.
  2. The ZX81 draws a multiplication as rows of small blocks: the number of rows times the number of blocks in a row. The blocks are grouped in fives, across and down, so you can count them.
  3. Say the answer out loud before the pause is over.
  4. The ZX81 then shows the answer. Check yourself.
  5. After ten multiplications the screen is cleared. Press New game to play again.
The program

A real ZX81 BASIC program running in an emulated ZX81. In the listing, \' stands for the ZX81 quarter-block character (top-left quarter).
